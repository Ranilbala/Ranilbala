## 🧑‍💻 About Me
 
I'm a Software Engineer II at **Expedia Group** on the Cloud Center of Excellence team. My work sits where cloud platform engineering, FinOps, and infrastructure automation meet.
 
- ☁️ I build internal platforms that pull cloud savings insights into one place and help engineering teams act on optimization recommendations.
- ⚙️ I automate infrastructure-as-code workflows so that optimizations ship through the same review path as any other change.
- 🧠 I'm going deeper on distributed systems and system design, and I learn by building small tools end to end.
